# Changing Number

> **반복적인 폴더 / 파일 순번 변경 작업을 자동화한 개인 프로젝트**

`Python` `GUI` `Automation`

## Why?

행정 업무를 하면서 여러 폴더와 파일의 순번을 반복적으로 변경해야 하는 작업을 발견했습니다.

작은 작업이지만 수작업으로 처리하면 시간이 걸리고 순서를 잘못 입력할 가능성도 있었습니다.

그래서 단순 반복 작업을 프로그램으로 옮겼습니다.

## What It Does

- 폴더 / 파일 순번 일괄 변경
- 반복 작업 자동화
- GUI 기반 조작
- 작업 결과 확인

기존의 단순한 번호 변경 기능에서 시작해 실제 업무에서 사용하기 편한 방향으로 기능을 확장했습니다.

## Design Goal

이 프로젝트에서 중요하게 본 것은 복잡한 알고리즘이 아니라 **실제 사용자가 실수 없이 사용할 수 있는 도구**를 만드는 것이었습니다.

CLI 대신 GUI를 사용하고, 작업 순서를 직접 확인할 수 있도록 구성했습니다.

## Context

가천대학교 반도체사업단 근로장학생으로 업무하면서 발견한 반복 작업을 개인적으로 자동화한 프로젝트입니다.

같은 업무에서 PDF 자동 분할, 근로 시간표 생성 등 다른 자동화 도구도 함께 제작했습니다.

## Tech Stack

`Python`

## What I Learned

작은 자동화라도 실제 업무에 적용하려면 단순히 기능을 구현하는 것보다 **사용자의 작업 흐름과 실수 가능성을 먼저 생각해야 한다는 점**을 경험했습니다.
